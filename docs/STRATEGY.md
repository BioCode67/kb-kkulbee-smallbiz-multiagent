# 꿀비 — 출품 전략 (제8회 KB AI Challenge)

팀: KB-꿀비 (꿀정보 모아주는 AI 비서: 꿀비) · 제출 2026-08-03

## 1. 지난 대회의 패인을 피한다

7회 출품작 '사장님의 꿀벌 비서'는 **텍스트로 정보를 모아 보여주는 데
그쳐** 수상하지 못했습니다. 정보 집약만으로는 검색과 다르지 않다는 것이
교훈이었습니다. 이번에는 같은 실수를 반복하지 않도록 세 가지를
'보이는 형태'로 바꿨습니다.

| 7회 (탈락) | 8회 꿀비 |
|---|---|
| 텍스트 나열 | **3D 공간 에이전트** — 지도 투어·경쟁 점포 열지도·비교 상권 |
| 고정된 답변 화면 | **Generative UI** — 질문에 따라 벤토 그리드가 달리 조립됨 |
| 근거 없는 요약 | **SHAP 방식 요인 채점** — 기준점 대비 요인별 ±점 기여 공개 |
| 표현 검증 없음 | **금소법 가드레일** — 나가는 모든 문장이 마지막 관문을 거침 |

## 2. Pick 4(소비자 보호) 전면 커버

1. **분쟁·독소조항 분석** — 분쟁 유형 6종 판별, 계약서 독소조항 10유형
   검사(PDF는 브라우저 안에서만 읽고 서버로 보내지 않음)
2. **쉬운 용어 사전 15개** — '금소법이 뭐야?'에 원문 그대로 답함
3. **절차 4단계 + 서류 체크리스트** — 창구에 들고 갈 수 있는 형태로 생성
4. **금소법 자동 재작성** — 단정·과장 표현을 예외 없이 걸러 고쳐 내보냄

## 3. 데이터 원칙 — 실데이터, 무날조

- 상권: 공공데이터포털 「소상공인시장진흥공단 상가(상권)정보」
  2026-03-31판 **전국 2,725,318개 점포 전량**을 색인해 탑재
  (`location_agent.py` · `market_data.py`). mock 데이터는 쓰지 않으며,
  자료에 없는 것(유동인구·매출·폐업률)은 화면에 "안 넣었다"고 적습니다.
- 정책자금: 기업마당 실공고 900건 직접 수집 · 하이브리드 검색 P@1 0.875
- 시세·경기: 부동산원 R-ONE(임대가격지수·공실률·임대료), 금감원 금리
  공시, 공정위 가맹 통계 — 전부 실시간 Open API + 하루 캐시
- 확장 계획: 상가정보도 소진공 상권정보 Open API 실시간 연동으로 전환

## 4. 화면 밖 실행 이력

1. **SW 저작권 출원 완료** — '3D 공간 에이전트 + SHAP 방식 요인 채점
   멀티에이전트 아키텍처' 소프트웨어 저작권 등록 출원
2. **현장 검증 완료** — 대구·경산 소상공인 3곳(신전떡볶이 동성로점,
   1058맨, 단디피트니스 계양점) 현장 UX 테스트·인터뷰. 정책자금 신청의
   복잡함, 상권 변화 체감이라는 실제 고충을 벤토 그리드와 3D 꿀비
   상호작용 개선에 반영
3. **기관 협업 추진 중** — 지역 소상공인지원센터와 실데이터 연계·시범
   배치 협의 진행
