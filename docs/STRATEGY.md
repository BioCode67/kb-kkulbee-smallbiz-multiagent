## 1. 승부수 — 작년 패인의 반대편에 선다

제7회 본선 **「사장님의 꿀벌 비서」**는 흩어진 정보를 모아 텍스트로 보여주는
서비스였고, 거기서 멈춰 수상하지 못했다. 꿀비는 같은 소재(소상공인 정보)를
다루되 **'보여주기'가 아니라 '실측으로 답하고 증명하는'** 쪽에 선다.

| 축 | 작년 유사작 (텍스트 나열) | 꿀비 |
|---|---|---|
| 경험 | 정보 요약 텍스트 | **3D 공간 에이전트**(절차적 꿀비·시네마틱 지도 투어) + **생성형 UI**(질문마다 벤토 그리드가 다르게 조립) |
| 설명력 | 점수만 제시 | **SHAP식 요인 채점** — 기준점 50에서 요인별 ±%p 기여를 가법 분해, 전국 백분위 근거 |
| 안전성 | AI 답변 그대로 노출 | **금소법 §19·20·21 가드레일**을 그래프 마지막 노드로 구조 보장 |
| 신뢰 | 출처 불명 | 전 항목 원문 링크 + 글라스박스 실측 로그 + "없는 자료는 없다" 명시 |

  `SBIZ_API_KEY` 설정 시 소진공 상권정보 Open API 반경 조회 활성.
  키가 없으면 자동으로 파일 색인 폴백(현행 기본값) — 시연 환경을 타지 않는다.
