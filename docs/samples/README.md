# 계약서 신호등 — 시연용 예시 계약서 PDF

'계약서 신호등 — 서명하기 전에 확인하세요' 카드에 끌어다 넣어 보는 가상의
계약서 3부입니다. 독소조항 규칙 10유형(`backend/app/services/contract_scan.py`)에
실제로 걸리는 문장을 일부러 심어 두었고, 열 유형 전부가 두 '독소' 문서에
나눠 담겨 한 번씩 시연됩니다.

| 파일 | 내용 | 기대 결과 |
|---|---|---|
| `예시계약서_임대차_독소조항.pdf` | 상가 임대차 — 불리한 조항 6개를 심음 | 🚨 위험 3 · ⚠️ 주의 3 |
| `예시계약서_프랜차이즈_독소조항.pdf` | 가맹계약 — 불리한 조항 4개를 심음 | 🚨 위험 1 · ⚠️ 주의 3 |
| `예시계약서_임대차_안전.pdf` | 같은 임대차를 법이 정한 모습대로 적은 대조군 | 🟢 초록불 (0건) |

걸리는 조항
- **임대차_독소조항** — 위험: 권리금 포기 특약(제5조) · 과도한 차임 인상
  여지(제4조) · 임대인 일방 해지(제6조) / 주의: 자동 연장(제7조) ·
  연대보증 요구(제8조) · 원상복구 범위 불명확(제9조)
- **프랜차이즈_독소조항** — 위험: 계약갱신 요구 배제(제3조) / 주의:
  광고·판촉비 일방 전가(제4조) · 경업금지 과다(제5조) · 과도한
  위약금(제6조)
- **임대차_안전** — 걸리는 조항 없음. 초록불이 '아무거나 통과'가 아니라는
  것을 보이는 대조군입니다(갱신요구권 10년·증액 상한 5%·권리금 보호를
  법대로 적음).

## 쓰는 법

첫 화면의 '계약서 신호등' 카드에서 PDF를 입력 칸에 **끌어다 놓거나**
`PDF 파일로 검사` 버튼으로 선택합니다. 파일은 서버로 올라가지 않습니다 —
pdf.js가 브라우저 안에서 글자를 뽑고, 문구만 검사로 보냅니다.

## 다시 만들기

```bash
cd backend
pip install reportlab fonttools brotli pypdf   # 만들 때만 필요 — 서빙 requirements에 없음
python -m scripts.make_contract_samples
```

만들면서 pypdf로 글자를 도로 뽑아 같은 `scan()` 규칙에 넣어, 기대한 조항이
'정확히 그것만' 걸리는지 검증합니다. 어긋나면 실패로 죽습니다. 글꼴은
프런트가 쓰는 고운바탕(woff2)을 TTF로 변환해 심으므로 스캔 이미지가 아닌
텍스트 PDF입니다.

## 주의

세 부 모두 시연을 위해 만든 **허구 문서**입니다(인물·상호·주소·금액 전부).
각 장 하단에도 같은 문구가 박혀 있습니다. 자동 검사는 등록된 10유형만 보는
참고용이며 법률 자문이 아닙니다.
