## 제출 전 5분 확인 (권장 순서)

0. 실서비스를 먼저 한 번 열고 30초 대기 — 무료 서버는 15분 놀면 잠들어
   첫 로딩이 느립니다. (실패 화면이 떠도 '다시 물어보기' 한 번이면 이어짐)
1. 아무 질문 하나 → 4단계 로딩 진행 패널 → 답변 + 왼쪽 글라스박스 콘솔
2. '기회 업종' 배너 → 연남동 → 빈 자리 찾기
3. '자금 찾기' 배너 → 5000만원 조달 설계 → "474만원 아낍니다" 카드
4. '권리 지키기' 배너 → 예시 계약서 검사(신호등) + 골든타임 날짜 계산
5. "연남동이랑 성수동 카페 상권 비교해줘" → VS 카드 + 줄다리기 승부표
- 자동 점검을 돌리고 싶으면: `cd backend && BASE=https://kb-kkulbee-smallbiz-multiagent.onrender.com python -m scripts.e2e_smoke` (16항목)
